# 선택적 예약 실행

사용자가 예약 주기와 무인 공개 발행을 요청했을 때만 설정한다. 기본 설치는 예약을 만들지 않는다. 먼저 수동 미리보기와 계정 발행을 확인한다.

`.env`에서 `IG_AUTO_PUBLISH=1`을 설정하면 `lumistory_auto.py`가 실제 공개한다. 기본 0이면 중단한다. Windows 작업 스케줄러는 이 전체 저장소의 `run_insta_daily.bat` 절대 경로를 사용한다. “시작 위치”도 저장소 루트로 지정하고 사용자가 정한 시각으로 등록한다. 동시에 두 인스턴스를 실행하지 않는 옵션을 선택한다. 경로를 옮기면 작업도 수정한다.

자동 실행은 RSS 순서대로 무료 다운로드가 있고 발행 이력에 없는 글 하나를 고른다. 테마는 발행 이력에 따라 1~10을 순환한다. 새 글이 없으면 게시하지 않는다. 생성 후 매번 사람의 확인을 기다리지 않으므로 이 자동 모드 선택 전에 동작을 확인해야 한다.

DM 예약은 별도 `run_insta_dm.bat`/`lumistory_dm_auto.py`와 `IG_AUTO_DM=1`이 필요하다. 기본 0이다. 댓글 키워드는 `IG_DM_KEYWORD`(기본 무료파일). 권한 확인 후 사용자가 정한 주기로 등록한다. 자동 카드에 DM 안내도 넣고 싶으면 `IG_INCLUDE_DM_CTA=1`을 별도로 설정한다.

macOS/Linux는 동일한 가상환경 Python과 스크립트 절대 경로를 로컬 스케줄러에 등록한다. 이 저장소는 그 운영체제용 자동 등록기를 제공하지 않는다. 컴퓨터가 켜져 있고 네트워크 연결과 계정 설정이 유효해야 한다. AI CLI 로그인은 필요하지 않다.

해제: 스케줄러의 해당 작업을 비활성화하고 `.env`의 두 자동 실행값을 0으로 바꾼다. `scheduler_run.log`, `published_log.json`, `dm_sent_log.json`은 로컬 기록이며 공유·커밋하지 않는다.
