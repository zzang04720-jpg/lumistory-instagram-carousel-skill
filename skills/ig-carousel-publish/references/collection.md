# 1단계 상세 — 정보 수집

목표: 카드뉴스 6~10장을 채울 수 있을 만큼 **구체적인** 정부 지원금/정책 정보 1건을 확보한다.
(gov-threads-publish 스킬의 수집 단계와 동일한 소스를 쓴다 — 같은 글감을 카드뉴스로 재가공하는 구조이므로
이미 그날 gov-threads-publish를 실행했다면 그 결과 텍스트를 그대로 재사용해도 된다.)

## 0. 키워드 지정 수집 (사용자가 키워드를 준 경우 — 최우선)

사용자가 "**○○ 검색해서 카드뉴스 만들어줘**" / "**○○로 만들어줘**"처럼 키워드를 주면,
korea.kr 목록 브라우징을 건너뛰고 **그 키워드로 바로 검색**한다. 아래 순서로 자동 처리:

1. **네이버 검색 MCP**로 키워드 검색 (있으면 우선):
   - `NaverSearch-search_news`(키워드) → 최신 뉴스/공고, 없으면 `NaverSearch-search_webkr`
   - 여러 건이면 아래 기준으로 **1건 자동 선별**:
     - 신규 지원/신청 접수 공고 우선 (회고·통계성 제외)
     - 금액·대상·신청기간이 **구체적으로 드러나는** 글 우선 (슬라이드 채우기 쉬움)
     - 가능한 한 **최근 것**, 그리고 정부/공식 출처(korea.kr, 부처, 지자체) 우선
2. MCP가 없거나 결과가 부실하면 **Chrome 폴백**: 네이버/구글에서 `키워드 + 지원금 신청`으로 검색해
   공식 공고 페이지를 열고 `get_page_text`로 본문 확보.
3. 선택한 공고 원문을 열어 **아래 3번 "추출해야 하는 항목"** 그대로 뽑는다.
4. 정보가 슬라이드 6~10장을 채우기에 부족하면, 같은 키워드로 1~2건 더 찾아 **보강**한다
   (단, 서로 다른 사업을 억지로 합치지 말고 한 사업으로 일관되게).

> 이 경로도 이후 흐름(카피→슬라이드→캡션→발행)은 동일하며, 사람이 채팅으로 시켰으므로
> **모드 B(수동)** — 마지막에 슬라이드·캡션 미리보기를 보여주고 승인받아 발행한다.

## 1. 1차 소스 — korea.kr (키워드가 없을 때의 기본)

Chrome으로 이동:
```
https://www.korea.kr/news/policyNewsList.do?smenu=EDS01
```

목록에서 아래 기준으로 1건을 고른다:
- **신규 지원/혜택 공고** 우선 (예: "○○ 지원금 신청 접수", "○○ 바우처 신청 시작")
- 단순 회고·통계 발표성 기사는 제외
- 청년/취준생/소상공인 등 타겟이 명확한 글 우선 (카드뉴스 타겟팅이 쉬움)

선택한 기사를 열어 `get_page_text`로 본문을 가져온다.

## 2. 폴백 — 네이버 검색

korea.kr 접속이 막히거나 적합한 글이 없으면 `NaverSearch-search_news` 또는 `search_webkr`로
`"2026년 지원금"`, `"정부지원금 신청"` 등의 키워드로 검색해 최신 공고를 찾는다.

## 3. 추출해야 하는 항목

카드뉴스는 슬라이드마다 정보를 나눠 담기 때문에, 기사보다 더 구조화된 추출이 필요하다:

- **제목/사업명**
- **한줄 요약** (표지에 쓸 후킹 문구의 재료)
- **지원 대상** (나이/소득/지역 등 조건)
- **지원 금액/혜택** (숫자를 명확히 — 강조 박스에 들어갈 핵심 재료)
- **신청 기간/마감일**
- **신청 방법** (온라인/오프라인, 사이트명)
- **신청 사이트 URL** (캡션 출처 링크용)
- **유의사항/팁** (있다면 — 정보 슬라이드 한 장 더 채울 수 있음)

이 항목들이 곧 정보 슬라이드 각각의 재료가 된다 (대상 1장, 금액 1장, 기간 1장, 방법 1장 식으로 나눠 담는다).

## 4. 저장

```bash
# insta_auto/YYYY-MM-DD.txt 로 저장
```

다음 형식으로 정리해서 저장한다 (2단계 카피 작성에서 그대로 가져다 쓴다):
```
제목:
한줄요약:
대상:
금액/혜택:
신청기간:
신청방법:
출처URL:
유의사항:
```
