# 시작 가이드 (초보자용)

## 설치 순서 (딱 5단계)

### 1단계 — 폴더 받기
선생님한테 받은 `insta_auto` 폴더를 바탕화면 등 원하는 위치에 저장한다.

### 2단계 — VS Code로 폴더 열기
VS Code → **파일 → 폴더 열기** → `insta_auto` 폴더 선택

### 3단계 — API 발급 시작
Claude Code 채팅창에 아래 문장을 그대로 입력:
```
인스타 API 발급부터 해줘
```
Claude가 자동으로 아래를 진행한다:
- Python 패키지 설치 (playwright, httpx 등)
- Cloudinary 가입 안내 → 복사한 키 `.env`에 저장
- Chrome을 열어 Meta 개발자 앱 자동 생성
- Instagram 토큰 자동 발급 + `.env`에 저장

**수강생이 직접 해야 하는 것은 딱 3가지:**
1. Cloudinary 회원가입 후 Cloud Name / API Key / API Secret 복사
2. 브라우저에 Facebook 계정 로그인된 상태로 두기
3. Claude가 열어주는 Instagram 권한 요청 화면에서 **"허용" 버튼 클릭**

### 4단계 — 프로필 사진 넣기
`insta_auto/avatar.jpg` 위치에 본인 프로필 사진을 복사한다.  
(파일명 반드시 `avatar.jpg`)

### 5단계 — 첫 카드뉴스
```
오늘 카드뉴스 만들어줘
```
입력하면 정보 수집 → 슬라이드 생성 → Cloudinary 업로드 → Instagram 자동 발행까지 한 번에 된다.

## 배경 이미지 (자동 처리)

슬라이드 배경(다크 카드 위 사진)은 아래 순서로 **항상 1장 자동 확보**된다:
1. **A.** 기사 썸네일 다운로드
2. **B.** 기사 본문 이미지 다운로드 (★언론사 저작권 이미지 `무단 전재/재배포 금지/©`는 제외,
   정부 제공 `자료=/제공=`만 사용 / 캡처가 아니라 원본 파일 다운로드 / 너무 저해상도면 건너뜀)
3. **C.** Pexels 무료 사진 (키가 있을 때)
4. **D.** 키리스 무료 사진(picsum) — **키가 없어도 무조건 1장 확보** → 순검정으로 안 빠짐

즉 별도 설정 없이도 사진이 항상 들어간다. **Pexels 무료 가입**(pexels.com/api, 카드 불필요) 후
`.env`에 `PEXELS_API_KEY=발급받은키`를 넣으면 **주제에 더 맞는 사진**이 나온다(선택).

## 매일 자동 발행 (선택 · 로컬 방식, Windows/Mac)

```
매일 오전 11시에 자동 발행 예약해줘      (시각은 자유 — "저녁 9시에", "아침 8시반에" 등)
```
Claude가 **말한 시각**에 맞춰 **이 컴퓨터의 로컬 스케줄러**(Mac=launchd / Windows=작업 스케줄러)를
자동 등록하고 매일 알아서 올린다. **클라우드도 git도 쓰지 않는다.**

▶ **작동 조건**: 예약 시각에 **컴퓨터가 켜져 있고 + Claude Code에 로그인돼 있어야** 한다.
(꺼져 있으면 그 날은 건너뜀. 클라우드가 대신 돌리지 않음.)
같은 주제는 다시 올리지 않는다 (중복 방지 자동).
자세한 설치·끄기·시간변경·문제해결은 `references/schedule.md` 참고.

## 자주 쓰는 명령어

| 입력 | 동작 |
|---|---|
| `오늘 카드뉴스 만들어줘` | 오늘자 정부 지원금 카드뉴스 생성 → 미리보기 확인 후 발행 |
| `○○ 검색해서 카드뉴스 만들어줘` | 원하는 키워드로 검색·수집해서 생성 → 미리보기 확인 후 발행 |
| `인스타 API 발급부터 해줘` | 최초 1회 API 세팅 |
| `매일 오전 11시에 자동 발행 예약해줘` | 일일 자동 발행 예약 (시각 자유, 로컬 방식) |
